# 📘 Estudos em JavaScript com Node.js

Este repositório é dedicado aos meus estudos em JavaScript, com foco no ambiente Node.js, explorando desde os fundamentos até conceitos mais avançados e boas práticas de desenvolvimento.

---

## 🚀 Conteúdo Estudado

### ✅ Fundamentos do JavaScript
- Variáveis, tipos, operadores
- Funções, escopo, hoisting
- Módulos e estrutura de projetos

### ✅ Programação Orientada a Objetos (POO)
- Classes, herança, encapsulamento
- Métodos estáticos e instanciados
- Prototype e herança prototípica

### ✅ Assíncrono no Node.js
- Callbacks, Promises e async/await
- Manipulação de eventos
- Trabalhando com arquivos e streams
